# 2주차 자동차 경주 

---

### 어떻게 설계하면 좋을까?
- **이야기**
    - 자동차 경주 게임을 한다.
        - n대의 자동차는 전진 또는 멈출 수 있다 = 서로 다른 자동차가 동시에 수행될 수 있다.
      </br></br>
- **협력: 요청과 응답**
    - **요청:**
        1. 각 자동차에 이름을 부여할 수 있다.
        2. 자동차 이름은 쉼표(,)를 기준으로 구분하며 이름은 5자 이하만 가능하다. 
        * <span style="background-color: #808080">💣 이름의 len을 확인한다.</span>
        3. 사용자는 몇 번 시도할 것인지 입력한다.
        4. 각 자동차의 전진 가능 여부를 `Randoms`를 통해 정한다. 
           * 전진하는 조건은 0에서 9 사이에서 무작위 값을 구한다.
             * <span style="background-color: #808080">💣 무작위 값이 4 이상일 경우에만 전진한다.</span>
                        </br></br>
    - **응답:**
        1. 자동차 경주 게임을 완료한 후 누가 우승했는지를 알려준다.
            1. 전진하는 자동차를 출력할 때 자동차 이름을 같이 출력한다.
            2. (한 명 이상일 때) 우승자가 여러 명일 경우 쉼표(,)를 이용하여 구분한다.
               </br></br>
- **책임: 하는 것과 아는 것**
    1. **하는 것:**
        1. 자동차가 전진한다.
        2. 전진 가능 여부를 랜덤 숫자로 뽑는다.
        3. 전진할 때마다 “-”가 늘어난다.
           </br></br>
    2. **아는 것:**
        1. 몇 번의 시도가 이루어지는지 알고 있다. (사용자의 입력값)
        2. (”하는 것”의 c.) 시도 횟수에 따라 증가한 “-”를 가지고 최종 우승을 알 수 있다.
           </br></br>
- **역할: 책임의 집합(재사용성)**
    - 자동차(Car)
        - 자동차 이름 : “요청” 2번 조건을 만족해야 함.
    - 자동차 전진 횟수 계산(CarMoveCount)
        - RandomGenerator에서 추출한 값을 통해 전진할 수 있는지 판단한다. : “요청” 3번 조건을 만족해야 함.
    - 전체 우승자 결과 = 총 전진한 횟수(TotalCount)
        - 이때 서로 다른 자동차의 총 전진 횟수(실행 결과)를 카운트 한다.
    - 랜덤 숫자 생성(RandomGenerator)
        - 주어진 API를 활용한다.
          </br></br>
- **에러 처리**
    - 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시킨 후 애플리케이션은 종료되어야 한다.

## 🔖 Model
### 1. Car
* 자동차 이름을 검증한다. 
  * 이름은 5자 이하만 가능하다.
    * 아닐 경우, `IllegalArgumentException`를 발생시킨다. 

### 2. CarMoveCount
* `RandomGenerator`에서 추출한 값에 따라 전진한다. 
  * 랜덤 숫자가 4 이상이 아닐 경우에는 전진하지 않고 멈춰 있는다. 

### 3. TotalCount
* 사용자가 입력한 값만큼 시도를 완료했을 때, 각 자동차가 얼만큼 전진하였는지 카운트한다. 
  * 최종 카운트 한 값으로 우승자가 나뉘어 진다. 

### 4. RandomGenerator
* 랜덤 숫자를 추출한다.

---
## 🖥️ View
### InputView
* 입력을 받는다.
    * `경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)`
    * `시도할 횟수는 몇 회인가요?`

### OutputView
* 출력을 한다. (예시)
    * `실행 결과
    pobi : -
    woni :
    jun : - `

---
## ⚙️ Contrller
### CarController
* `InputView`를 통해 `Car`을 호출한다. 
* `CarMoveCount`를 통해 각 자동차가 전진하고,
* `TotalCount`를 통해(총 전진 횟수) 우승자를 결정한다. 
* `OutputView`를 호출한다.

## 🧪 테스트 코드
1. `Car`
   *  자동차 이름은 5자 이하만 가능하다.
   *  자동차 이름에 null이나 공백이 들어오면 안된다.
   *  자동차 이름을 적을 때 쉼표가 아닌 다른 문자가 오면 안된다.
   <br> <br> 
2. `CarMoveCount`
   * 랜덤 숫자가 4 미만이면 전진(움직이지)하지 않는다.
   * 랜덤 숫자가 4 이상이면 전진(움직여야)해야 한다.
   * 전진할 때 문자열 “-”로 출력되어야 한다.
   * 올바른 실행결과를 반환해야 한다.
     <br> <br>
3. `TotalCount`
   *  올바른 최종결과를 반환해야 한다.
     <br> <br>
4. `RandomGenerator`
   * 자동으로 랜덤 숫자를 생성해 주기 때문에 따로 테스트 코드는 필요하지 않다고 생각한다.
     <br> <br>
5. `전체`
   * 시도할 횟수 입력값에 문자를 입력하면 안된다. (숫자를 입력해야 한다) 
   * 시도할 횟수 입력값에 음수를 입력하면 안된다.
